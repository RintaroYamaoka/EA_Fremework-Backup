EA_Framework-Backup

本リポジトリは個人制作物（個人開発）です。
趣味としてアルゴリズムトレード（EA）開発を行うための、自分用バックアップを目的に管理しています。
業務コードや機密情報は含まれていません。

このリポジトリは提出用に整理された成果物ではなく、開発途中のEAや検証用ファイル、過去バージョンも含みます。
そのため、構成や命名は頻繁に変更されます。


目的

  EA開発に必要な共通処理を分離し、戦略部分を差し替えて検証しやすくする
  注文、ポジション管理、セッション制御、シグナル判定、ロット計算などを役割ごとに分けて管理する
  Walk-Forward Analysis（WFA）や検証の反復を前提に、保守しやすい形を目指す


含まれるもの

  Modules 配下の各種モジュール（注文、ポジション、シグナル、セッション等）
  製作中のEA群（検証・実験段階のものを含む）
  Versions フォルダ（過去バージョンの保管用）
  LimitedTest 系（限定条件でのテスト用）


注意点

  本リポジトリは個人用バックアップを含むため、全体としては雑多な構成になっています
  自動取引を行うEAを効率良く量産、検証するためのフォルダ全体のバックアップです
  必要に応じて、特定のトレードシステム、モジュールや設計方針を面談で説明できます


開発環境

  MetaTrader 5
  MQL5
